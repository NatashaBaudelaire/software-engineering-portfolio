## Project Overview

A personal collection of self-contained coursework and exercises spanning programming fundamentals, database design, cloud computing, software testing, and data science. It documents a progressive learning path across multiple technologies and methodologies.

## Technologies Used

- Java (JDK 8+) with JUnit 5
- Python 3.10+
- SQL / Database Modeling (conceptual, logical, and physical design)
- Cloud Computing (Google Cloud, AWS)
- Jupyter Notebook - pandas, NumPy, Matplotlib, Seaborn, scikit-learn

## Repository Structure

```
01-programming-languages/   # Java & Python - algorithms, OOP, file handling
02-databases/                # Conceptual, logical, and physical models
03-cloud-computing/          # Apache, FTP, HTTP traffic analysis
04-software-testing/         # Manual, test-case design, and unit testing
05-artificial-intelligence/  # Module notes and learning roadmap
06-data-science/             # Analysis, preprocessing, and visualization notebooks
```

Each module has its own `README.md` with exercise details and run instructions.

## Learning Progression

1. **Fundamental Programming** - algorithms and logic in Java and Python
2. **Object-Oriented Programming** - OOP concepts and design patterns
3. **Database Design** - data modeling and database architecture
4. **Cloud Infrastructure** - cloud services and deployment
5. **Software Quality** - automated and manual testing methodologies
6. **Advanced Topics** - AI/ML and data science applications

## Getting Started

- **Java**: JDK 8+, JUnit 5 for the test suites
- **Python**: 3.10+ (some scripts use `match`/`case`)
- **Jupyter**: `pip install jupyter pandas numpy matplotlib seaborn`

See each module's `README.md` for specific run instructions.
