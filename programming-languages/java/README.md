# Java Programming Exercises

Self-contained Java exercises covering fundamental programming concepts and
object-oriented programming. Completed as part of undergraduate software
engineering coursework.

## How to Run

### Prerequisites

- Java Development Kit (JDK) 8 or higher

### Compilation and Execution

```bash
cd algorithms-and-problem-solving/conditionals/weightedbillsplit
javac WeightedBillSplit.java
java weightedbillsplit.WeightedBillSplit
```

### Using an IDE

Open the `java` directory in your IDE, navigate to the exercise, and run the
`.java` file.

## Notes

- Each exercise is self-contained and runs independently.
- Package names follow the lowercase convention and match the directory
  structure.
- Class names follow PascalCase; variable names follow camelCase.
- Some exercises expect console input with a specific format.

## Learning Objectives

- Basic syntax: variables, data types, operators
- Control flow: if-else and loops
- Methods, arrays and collections
- Object-oriented programming: classes, objects, inheritance, encapsulation,
  aggregation and composition
- Console input/output and mathematical operations
