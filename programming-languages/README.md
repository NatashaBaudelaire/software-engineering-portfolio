# Programming Languages

Self-contained programming exercises organized **by language**, never by
framework or tool. Programming languages live here; framework-based content
lives in the knowledge domain that uses it, so languages stay cleanly
separated from libraries, platforms and environments.

| Framework / tool | Where it lives |
| --- | --- |
| Flutter / Dart | [Mobile Development](../mobile-development/README.md) |
| JUnit 5 | [Software Testing](../software-testing/README.md) |
| TensorFlow / Keras | [Artificial Intelligence](../artificial-intelligence/README.md) |
| scikit-learn / pandas / Jupyter | [Data Science](../data-science/README.md) |
| SQL | [Database Design](../database-design/README.md) |

## Directory Structure

- [`java/`](java/README.md) - Java exercises: algorithms & problem solving,
  then object-oriented programming (encapsulation, inheritance,
  aggregation/composition).
- [`python/`](python/README.md) - Python exercises: algorithms & problem
  solving, functions and file handling (`organize_files.py`).

Both languages share the same exercise taxonomy so concepts can be compared
across the two languages.

## Language Boundary

- `programming-languages/` contains **only** code and exercises for the
  language itself.
- Anything that requires a specific platform, framework or skill domain
  (Flutter apps, JUnit test suites, Keras models, SQL schemas) is stored in
  its corresponding domain at the repository root.

## Learning Objectives

- Compare the same algorithmic concepts across Java and Python
- Keep language practice separate from framework-based coursework
- Navigate exercises by topic: conditionals, loops, strings,
  mathematical-calculations, variables-and-input
