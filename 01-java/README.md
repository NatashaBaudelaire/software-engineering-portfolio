## How to Run the Exercises

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Text editor or IDE (IntelliJ IDEA, Eclipse, VS Code)

### Compilation and Execution

```bash
# Navigate to the specific exercise directory
cd algorithms-and-logic/conditionals/weightedbillsplit

# Compile the Java file
javac WeightedBillSplit.java

# Run the compiled program
java weightedbillsplit.WeightedBillSplit
```

### Using an IDE
1. Open the entire `01-java` directory in your IDE
2. Navigate to the specific exercise
3. Right-click on the `.java` file and select "Run" or "Debug"

## Notes

- All package names follow lowercase convention to match directory structure
- Variable names follow camelCase convention
- Class names follow PascalCase convention
- Each exercise is self-contained and can be run independently
- Some exercises may require user input via console

## Common Issues

### Compilation Errors
- Ensure package name matches directory structure
- Check that class name matches file name
- Verify Java version compatibility

### Runtime Errors
- Some exercises expect specific input formats
- Check for proper input validation
- Ensure all required files are in the correct directory
