# Cloud Computing Labs

Hands-on infrastructure labs completed on the cloud (Google Cloud Shell) and
on local network setups. Each lab follows a step-by-step `tutorial-guide.txt`
and, where applicable, includes real command captures.

## Directory Structure

### `apache-cloud-shell`

Apache web server setup and testing on Google Cloud Shell.

- `tutorial-guide.txt` - step-by-step installation on port 8080
- `cloud-shell-welcome.txt` - environment welcome output

### `ftp-server`

FTP server installation and practice with file transfer operations.

- `tutorial-guide.txt` - setup and usage guide
- `cloud-shell-welcome.txt` - environment welcome output
- `ftp-capture.txt` - real FTP session capture

### `http-traffic-analysis`

HTTP traffic capture and analysis.

- `tutorial-guide.txt` - guiding commands for capturing traffic
- `http-capture.txt` - real HTTP request/response capture

## How to Use

Open the `tutorial-guide.txt` of the desired lab and follow the commands in a
cloud shell or terminal.

## Learning Objectives

- Cloud shell usage and environment setup
- Installing, configuring and testing an Apache web server
- FTP server setup and file transfer practice
- HTTP protocol inspection and traffic capture analysis
- Command-line troubleshooting in cloud environments
