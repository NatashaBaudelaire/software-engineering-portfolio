# my_first_app

First Flutter app, created during the "Getting started with Flutter" mobile
development exercise.

## Features

- Material counter app (the Flutter default project as a starting point);
- each tap on the floating button increments the counter by **3**;
- a floating reset button restores the counter to zero;
- contextual message that changes as the count grows (`No taps yet`,
  `A few taps`, `A lot of taps!`).

## Running

```bash
flutter pub get
flutter run
```

## Tests

```bash
flutter test
```

The widget test verifies the increment-by-three behavior and the reset button.
